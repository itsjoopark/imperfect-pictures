# Assets Directory

Place your default image here with the name `joo.jpeg` or update the `defaultImgPath` variable in `sketch.js` to point to your image.

The image will be used as an alternative to the webcam feed when you press the 'W' key.

## Supported Formats
- JPEG
- PNG
- GIF

## Recommended Image Size
- At least 640x480 pixels for best results
